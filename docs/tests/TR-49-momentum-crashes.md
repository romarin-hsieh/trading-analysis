  −34.4%)——分歧集中於理論上該分歧的崩盤月。v2:corr≥0.95+最大落差月須在崩盤年代 → PASS。
  C 規格無跨用兩序列,分歧不污染判定。**教訓入資料真相:KF 日/月動量因子不可互為複利檢核。**

### C4 本 TR 的靈魂:預測 vs 目標

DM-lite 動態權重(狀態條件均值×1/σ²)vs BSC 單純波動目標,共同窗:
**DM 1.02/−34% vs BSC 0.98/−32%**——Sharpe 微勝但 MDD 反深,依預先承諾規則(兩軸皆勝
才算贏)**DM 未勝**。結論與 Moreira-Muir/我方八次鐵律確認同構:**崩盤的可預測性存在
(C2 顯著),但它的可交易內容已被單純的波動縮放張成**——連在動量因子這個「崩盤最戲劇化」
的座位上都是如此。此為鐵律的**異座位外部驗證**,不計入鐵律計數(不同座位;且因子層波動
管理本來就是現役機制)。
