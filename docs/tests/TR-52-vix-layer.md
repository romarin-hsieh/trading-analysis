## 後果

- **鐵律計數 8→9**,且這一次關閉的是例外條款本身的指數端:「除非來自選擇權資訊層」收窄為
  「除非來自**自建個股鏈**」(IV skew/期限結構的橫斷面,Theta EOD 滴灌 ~6 個月後可測——
  那是**擇股**用途,不再有任何開放的**擇時**通道)。

- BTZ 2009 加入發表後衰退案例集(TR-47 DBT 之後本週期第二例)。
